# Output guidelines

Use these default structures when the user does not specify one.

## Summary report (docx/pdf)

1. Title: `<topic> – summary`
2. Summary: 3–5 sentences.
3. Key facts: table with columns `Item | Value | Source`.
4. Details: one `##` section per theme.
5. Open points / action items: bullet list (`Action – Owner – Due date`).
6. Sources: list of source file names.

## Data table (xlsx)

- Sheet `Data`: one row per extracted record; first column is an identifier or name.
- Dates as `YYYY-MM-DD`; amounts as plain numbers without currency symbols (put the currency in
  the column header, for example `Amount (EUR)`).
- Sheet `Sources`: columns `Document | Notes`.

## Comparison (docx or xlsx)

- One column per document, one row per compared field.
- Highlight differences in a final `Differences` section (docx) or column (xlsx).
